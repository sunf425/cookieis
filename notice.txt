Review & Todo 업데이트 안내
Rev. r27_260827

이번 r27 업데이트에서는 r20 이후 추가된 메모/Todo 보기 기능, 태그 기능,
Wiki 형태의 메모 분류 기능, 프로젝트(@프로젝트) 기능을 한 번에 정리하고
모바일 프로젝트 UI와 프로젝트 동기화를 보강했습니다.

1. 공지사항
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

앱은 이제 버전별 공지 파일을 사용합니다.

이번 버전의 공지 파일:
notice_r27_260827.txt

브라우저 캐시에 이전 공지가 남는 문제를 줄이기 위해
앞으로 공지 파일은 버전별 파일명으로 제공합니다.

새 공지가 있으면 앱 시작 시 팝업으로 한 번 표시됩니다.
같은 공지를 이미 확인한 경우 다음 실행부터 자동으로 다시 표시하지 않습니다.

확인한 공지는 좌측 사이드패널 하단의 [공지사항] 메뉴에서 언제든 다시 볼 수 있습니다.

2. 메모 / Todo 4단계 보기
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📝✅ 버튼을 누를 때마다 아래 4가지 보기 모드가 순서대로 전환됩니다.

① 📝✅ 모두 보기
모든 메모 블럭을 표시합니다.

② 📝✅ Todo가 있는 블럭만 보기
Todo가 하나 이상 있는 메모 블럭만 표시합니다.
메모 본문과 Todo를 모두 함께 보여줍니다.
이 상태에서는 메모 이모지가 흐리게 표시됩니다.

③ ✅ Todo만 보기
Todo가 있는 블럭만 표시하되 메모 본문은 숨기고 Todo 내용에 집중합니다.

④ 📝 Todo가 없는 메모만 보기
Todo가 하나도 없는 메모 블럭만 표시합니다.

버튼의 이모지가 바뀌어도 버튼 폭은 고정되어
옆 버튼 위치가 움직이지 않습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. Wiki / 생각정리 기능
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Todo가 없는 메모는 할 일 목록이 아니라
생각 정리, 지식 기록, 자료 보관, 개인 Wiki처럼 사용할 수 있습니다.

📝 [Todo가 없는 메모만 보기] 모드를 사용하면
Todo가 붙은 실행형 메모를 제외하고 순수 메모/Wiki 블럭만 모아볼 수 있습니다.

예)
- 업무 규칙
- 회의에서 알게 된 정보
- 개발 구조 설명
- 참고 자료
- 아이디어 기록
- 제품/서비스 문서
- 개인 지식 베이스

즉,
Todo가 있는 블럭 = 실행/업무 관리
Todo가 없는 블럭 = 메모/Wiki/생각 정리
형태로 나누어 활용할 수 있습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
4. 태그 기능 #태그
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

메모에 #태그를 입력하면 태그로 인식합니다.

예)
#업무
#중요
#자료
#아이디어

#태그는 본문에서 진한 녹색 + 굵은 글씨로 표시됩니다.

태그 입력 후 스페이스, 줄바꿈, 편집 종료 시 바로 반영됩니다.
일반 문장을 입력할 때 스페이스를 눌러도 편집 상태가 종료되지 않습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. 태그 포함 / 제외 필터
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

좌측 태그를 일반 클릭하면 포함 필터입니다.
선택한 태그를 포함한 메모만 표시합니다.

태그를 마우스 오른쪽 버튼으로 클릭하면 제외 필터입니다.
제외 태그는 반투명 붉은색으로 표시됩니다.

제외 태그가 여러 개이면
그중 하나라도 포함한 메모는 현재 보기에서 제외됩니다.

포함 태그와 제외 태그는 동시에 사용할 수 있습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6. 프로젝트 기능 @프로젝트
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

프로젝트는 메모를 특정 업무, 장기 작업, 제품, 서비스,
고객, 개발 항목 등의 단위로 묶는 두 번째 종류의 태그입니다.

# 대신 @를 사용합니다.

예)
@홈페이지개편
@신제품런칭
@서비스리뉴얼
@개인공부

프로젝트의 실제 기준은 메모 본문의 @프로젝트명입니다.

별도의 프로젝트 DB 항목이 아니라
메모 텍스트에 들어 있는 @텍스트 자체가 프로젝트 정보입니다.

따라서 메모에 직접 @프로젝트명을 입력하면 바로 프로젝트로 인식됩니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
7. 프로젝트와 태그 함께 사용
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

#태그와 @프로젝트는 같은 메모에서 함께 사용할 수 있습니다.

예)

로그인 화면 수정
#개발 #중요 @홈페이지개편

#개발 / #중요
→ 태그

@홈페이지개편
→ 프로젝트

태그와 프로젝트는 서로 독립적으로 필터링할 수 있습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
8. 프로젝트 본문 표시
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

#태그:
진한 녹색 + Bold

@프로젝트:
진한 노랑~주황색 + Bold

메모를 읽을 때 태그와 프로젝트를 색으로 빠르게 구분할 수 있습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
9. 프로젝트 관리창
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

좌측 사이드패널의 노란색 [@프로젝트] 버튼을 누르면
프로젝트 선택/필터 창이 열립니다.

r27의 프로젝트 관리창은 선택/필터링 전용입니다.

프로젝트 관리창에서 프로젝트를 별도로 추가하거나 삭제하지 않습니다.

현재 메모 본문에 존재하는 @프로젝트명들을 자동으로 수집하여 보여줍니다.

새 프로젝트를 만들려면 메모에 새로운 @프로젝트명을 직접 입력하면 됩니다.

예)
새 기능 문서 작성 @모바일개편

이렇게 입력하면 @모바일개편 프로젝트가 자동으로 목록에 나타납니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
10. 프로젝트 필터링
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

프로젝트 관리창에서 원하는 프로젝트를 선택하고 [선택]을 누르면
선택한 프로젝트와 관련된 메모만 표시됩니다.

복수 프로젝트 선택도 가능합니다.

프로젝트 필터가 적용되어 있을 때는
좌측 @프로젝트 버튼에 [필터링 중] 표시가 나타납니다.

[전체 프로젝트 보기]를 누르면
프로젝트 필터가 즉시 해제되고 전체 메모 보기로 돌아갑니다.

[닫기] 또는 팝업 바깥의 어두운 영역을 누르면
관리창에서 바꾼 선택을 적용하지 않고 닫습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
11. 메모 왼쪽 프로젝트 점
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

프로젝트가 없는 메모:
일반 점

프로젝트가 있는 메모:
조금 더 크고 굵은 노란색 점 ●

목록을 훑을 때 어떤 메모가 프로젝트에 속해 있는지
빠르게 구분할 수 있습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
12. 메모별 프로젝트 지정
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

메모 왼쪽 점을 누르면 해당 메모의 프로젝트 선택창이 열립니다.

프로젝트를 선택하고 [확인]하면
해당 메모 끝에 @프로젝트명이 자동으로 추가됩니다.

예)

수정 전:
메인 화면 레이아웃 검토

수정 후:
메인 화면 레이아웃 검토 @홈페이지개편

프로젝트는 한 메모에 여러 개 사용할 수 있습니다.

예)
공통 로그인 구조 검토 @웹서비스 @모바일앱


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
13. 프로젝트 제거
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

메모별 프로젝트 선택창에서 [프로젝트 없음/제거]를 사용하면
해당 메모의 @프로젝트 연결을 제거할 수 있습니다.

프로젝트의 실제 기준은 메모 본문 @텍스트이므로
본문에서 직접 @프로젝트명을 삭제해도 동일합니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
14. 모바일 프로젝트 UI
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

모바일에서는 다음 세 버튼이 한 줄에 표시됩니다.

[검색] [태그] [@프로젝트]

@프로젝트 버튼은 노란색 박스로 표시됩니다.

프로젝트 필터가 적용 중이면
모바일 @프로젝트 버튼에도 [필터링 중] 상태가 표시됩니다.

메모 왼쪽 프로젝트 점은 모바일 터치/hover 상태에서도
위아래로 튀거나 위치가 바뀌지 않도록 고정했습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
15. 프로젝트 동기화
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

프로젝트 정보는 메모 본문의 @프로젝트명에 저장됩니다.

따라서 프로젝트가 지정된 메모의 본문이 Supabase에 동기화되면
다른 기기에서도 @프로젝트 정보가 그대로 따라갑니다.

r27에서는 메모 편집 중 내부 메모리 값이 먼저 바뀌어
편집 종료 시 변경을 놓칠 수 있던 부분을 보강했습니다.

이제 메모 편집 시작 시 원문을 기억하고,
편집 종료 시 실제 본문과 비교합니다.

내용이 달라졌으면:
- updatedAt 갱신
- localStorage 저장
- Supabase 즉시 동기화

를 수행합니다.

따라서 직접 @프로젝트명을 입력하거나 수정한 경우에도
편집 종료 후 프로젝트 정보가 동기화됩니다.

메모 왼쪽 점으로 프로젝트를 지정하는 경우에도
즉시 동기화를 요청합니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
16. 프로젝트 + 태그 + Todo/Wiki 조합
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

예시 1)
@홈페이지개편
#중요
Todo가 있는 블럭 보기

→ 홈페이지개편 프로젝트 중 중요 태그가 있고
Todo가 있는 메모만 볼 수 있습니다.

예시 2)
@개인공부
#자료
📝 Todo가 없는 메모 보기

→ 개인공부 프로젝트에서
자료/Wiki 성격의 순수 메모만 모아볼 수 있습니다.

예시 3)
@서비스리뉴얼
✅ Todo만 보기

→ 해당 프로젝트의 실행 항목만 집중해서 볼 수 있습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
17. 연속 메모 입력
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

새 메모 입력창에서 Ctrl+Enter 또는 Cmd+Enter로 저장하면
커서가 새 메모 입력창에 그대로 유지됩니다.

마우스를 다시 클릭하지 않고 다음 메모를 계속 입력할 수 있습니다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
18. 요약
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

#태그
- 메모의 성격/주제/상태 분류
- 진한 녹색 표시
- 포함/제외 필터 지원

@프로젝트
- 업무/서비스/장기 작업 단위 분류
- 노랑~주황색 표시
