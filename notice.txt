============================================================
1. 전체 구조 개편
============================================================

- 기존 Workspace 중심 구조에 Calendar 기능을 추가했습니다.
- 앱의 중심 데이터는 Item으로 유지됩니다.
- Item은 메모 + 체크리스트를 함께 가지며, Calendar는 Item을 복사하지 않고 같은 Item을 일정으로 배치합니다.
- Workspace / Calendar 두 가지 메인 모드로 정리했습니다.
- 기존 독립 Routine 메인 모드는 제거하고, Calendar 안의 Routine Dashboard로 통합했습니다.
- 기본 흐름은 다음과 같습니다.

  Capture → Plan → Execute → Review → Knowledge

- Calendar 단축키:
  `  = Workspace
  1  = Month
  2  = Week
  3  = Day
  4  = Week로 이동 후 Routine Dashboard 열기

============================================================
2. Calendar 기본 기능
============================================================

- Month / Week / Day 3가지 Calendar View를 추가했습니다.
- Daily Calendar는 다음 구조로 구성됩니다.

  좌측
  - 날짜 라벨 / 색상
  - Big3
  - Brain Dump
  - 미배치 Routine
  - 오늘의 메모
  - 오늘의 리뷰

  우측
  - 30분 단위 TimeTable

- 하루는 00:00~24:00 기준입니다.
- 기본적으로 이른 새벽 / 늦은 밤 영역은 접어둘 수 있습니다.
- 접힌 영역은 펼쳐서 볼 수 있습니다.
- 접힌 영역을 펼쳤을 때 일정 블록이 중간에서 잘리지 않고 하나의 연속 블록으로 표시됩니다.

============================================================
3. Daily TimeTable
============================================================

- 30분 단위 일정 배치 기능을 추가했습니다.
- 일정은 Brain Dump 상태 또는 특정 시간에 배치된 상태를 가질 수 있습니다.
- 일반 일정은 다음 조작을 지원합니다.

  - Drag & Drop으로 시간 이동
  - 위/아래 Resize Handle로 시작/종료 시간 조정
  - + / - 버튼으로 30분 단위 예상시간 증감
  - 30분에서 - 버튼을 누르면 Brain Dump로 이동
  - TimeTable의 일정 블록을 Brain Dump로 다시 Drag & Drop 가능
  - Brain Dump 항목을 TimeTable로 Drag & Drop 가능

- 일정 이동 / Resize는 다른 일반 일정과 충돌하면 거부됩니다.
- 자기 일정이 기존에 차지하고 있던 영역은 충돌 대상에서 제외되므로
  13:00~16:00 일정을 14:00~17:00처럼 이동할 수 있습니다.
- 완료된 일정은 이동 / Resize가 잠깁니다.
- 완료 취소 후 다시 편집할 수 있습니다.

- TimeTable 시간축:
  - 30분 가이드선은 유지
  - 시간 텍스트는 1시간 단위만 표시
  - 예: 13:00, 14:00, 15:00
  - 13:30, 14:30 텍스트는 표시하지 않음

============================================================
4. Weekly Calendar
============================================================

- Weekly 시작 요일을 월요일 시작에서 일요일~토요일 구조로 변경했습니다.
- Monthly의 한 주 배열과 Weekly의 한 주 배열이 동일합니다.

  일 / 월 / 화 / 수 / 목 / 금 / 토

- 일반 일정은 Weekly에서 날짜와 시간을 Drag & Drop으로 이동할 수 있습니다.
- Drop 위치는 30분 단위로 계산됩니다.
- 자기 일정 영역 안으로 이동하는 것도 가능합니다.
- 다른 일반 일정과 충돌하면 이동이 거부됩니다.

- Drag 중 Weekly 양쪽에 Overlay Drop Zone이 표시됩니다.

  ← 이전 주 월요일로 넘기기
  다음 주 월요일로 넘기기 →

- 이전/다음 주 Drop Zone에 놓으면:
  - 해당 주 월요일로 이동
  - Brain Dump 상태로 이동
  - 예상시간 유지
  - Big3 해제

- Weekly에서도 Routine 발생분을 Drag & Drop으로 이동할 수 있습니다.
- Routine을 다른 날짜로 옮기면 해당 날짜의 일회성 이동으로 처리됩니다.
- 반복요일 자체를 영구 변경하려면 Routine Dashboard의 수정 기능을 사용합니다.
- 같은 날짜에 동일한 Routine을 두 번 배치하는 것은 현재 허용하지 않습니다.

============================================================
5. Brain Dump 개선
============================================================

- Brain Dump 항목을 옅은 둥근 사각 카드 형태로 변경했습니다.
- 기존 텍스트 버튼 중심 UI를 아이콘 중심으로 정리했습니다.

  ➜  = 첫 번째 가능한 시간으로 Check-in
  ⚐/⚑ = Big3 지정 / 해제
  🗑 = 삭제

- Big3로 지정된 Brain Dump 항목은 카드, 제목, 깃발을 더 강하게 표시합니다.
- Brain Dump 카드 본체를 누르면 일정 편집 패널이 열립니다.
- Brain Dump 항목을 직접 TimeTable로 Drag & Drop해 원하는 시간에 배치할 수 있습니다.
- 기존 Brain Dump 내부의 "+ 새 할 일" 버튼은 제거했습니다.

6. Floating 새 할 일 버튼
============================================================

- Daily Calendar 우측 하단에 녹색 원형 + Floating 버튼을 추가했습니다.
- 버튼 옆에 Ctrl+Enter 안내 문구를 표시합니다.
- Calendar에서 다음 단축키로 동일한 새 할 일 팝업을 열 수 있습니다.

  Windows / Linux: Ctrl + Enter
  macOS: Cmd + Enter

============================================================
7. Big3
============================================================

- Big3는 Item을 복사하지 않고 동일한 Item을 참조합니다.
- 하루 최대 3개까지 지정할 수 있습니다.
- Daily / Weekly TimeBlock의 Big3는 일반 일정과 구분되도록 강조 색상과 BIG3 표시를 적용했습니다.
- 다른 날짜로 이동할 때 대상 날짜에 Big3가 이미 3개면 일정은 이동시키되 Big3는 해제합니다.
- 이전/다음 주 월요일 Brain Dump로 넘길 때 Big3는 자동 해제합니다.

============================================================
8. 일정 Item 편집 패널
============================================================

- Calendar의 일정 블록을 클릭하면 "일정" 편집 패널이 열립니다.
- Workspace의 원본 Item과 같은 데이터를 직접 편집합니다.
- 별도의 Calendar 복사본을 만들지 않습니다.

- 일정 패널에서 수정 가능한 내용:
  - 메모 본문
  - 체크리스트 추가
  - 체크리스트 수정
  - 체크리스트 완료 체크
  - 체크리스트 삭제
  - Workspace에서 열기

- 메모의 첫 번째 줄을 일정 제목으로 사용합니다.
- 두 번째 줄부터는 메모 / 기록 / 참고내용으로 취급합니다.

  예:
  첫 줄    → 일정 제목
  둘째 줄~ → 메모 내용

- Daily / Weekly TimeBlock:
  - 30분 일정: 제목만 표시
  - 1시간 이상: 제목 + 내용 존재 확인용 1줄 Preview
  - Preview는 최대 약 20자 후 ... 처리
  - 시작시간~종료시간 / 예상시간 문구는 TimeBlock에서 제거

- TimeBlock의 일반 영역 전체를 클릭하면 일정 패널이 열립니다.
- + / - / Big3 / Check! / Resize Handle 등 조작 버튼은 일정 패널 클릭과 분리되어 있습니다.
- ESC 키로 일정 패널을 닫을 수 있습니다.

  @프로젝트  → 주황색

10. 일정 완료 / Review
============================================================

- Calendar 일정에 Check! 완료 흐름을 추가했습니다.
- 완료 시 다음 내용을 기록합니다.

  - 계획 대비 결과
    😀 계획대로 됨
    🙂 일부만 됨
    😕 기대에 못 미침

  - 계획 대비 갭 / 원인
  - 다음번 개선점

- 완료 시 실제 확인 시각을 completedAt으로 기록합니다.
- 완료된 일정은 회색 처리됩니다.
- 완료 취소 기능을 지원합니다.
- 완료 취소 시 기존 Review는 삭제하지 않고 revoked 상태로 남깁니다.
- 다시 Check!할 때 최근 취소된 Review 내용을 자동으로 불러옵니다.
- 다시 완료하면 새로운 Review 기록을 생성합니다.

13. Routine V2
============================================================

- 기존 Routine V1은 사용자 UI에서 제거했습니다.
- 새 Routine V2를 Calendar 중심으로 운영합니다.
- Routine 데이터는 아직 기존 Supabase blocks 기반 구조를 유지합니다.

- Routine 설정:
  - 제목
  - 목표 / 설명
  - 반복 요일
  - 기본 시작시간
  - 기본 예상시간

- Routine은 Calendar에서 Soft Schedule로 표시됩니다.
- 일반 일정과 충돌하면 미배치 Routine으로 분리됩니다.
- 미배치 Routine은 Daily에서 다른 시간으로 Drag & Drop해 배치할 수 있습니다.
- 배치된 Routine도 Daily에서 Drag & Drop으로 시간 이동할 수 있습니다.
- Weekly에서도 날짜 / 시간 이동을 지원합니다.

- Routine 완료:
  - Routine TimeBlock에 Check! 버튼 제공
  - 일반 일정과 동일한 Review 입력
  - 완료 / 완료 취소 지원
  - 날짜별 Routine Log에 완료 기록 저장

============================================================
14. Routine Dashboard
============================================================

- 독립 Routine 페이지 대신 Calendar 안의 Routine Dashboard를 사용합니다.
- 4 키를 누르면:
  - Calendar Week로 이동
  - Routine Dashboard 자동 표시

- Dashboard 주요 기능:
  - Routine 추가 / 수정
  - 최근 30일 달성률
  - 완료한 날 수
  - 총 수행 횟수
  - 최고 연속 수행
  - Heatmap
  - Routine 목록

- 특정 Routine을 선택하면 해당 Routine의 전체 실행 기록을 한 화면에서 스크롤해 볼 수 있습니다.

  기록 내용:
  - 날짜
  - 완료 / 완료취소 상태
  - 계획 대비 결과
  - 갭 / 원인
  - 다음 개선점
  - 기존 note / value

- Routine Dashboard가 열려 있어도 다음 단축키를 사용할 수 있습니다.

  `  = Workspace
  1  = Month
  2  = Week
  3  = Day

  위 단축키를 누르면 Routine Dashboard를 닫고 해당 모드로 전환합니다.

15. Workspace 긴 메모 접기
============================================================

- Workspace 메모가 실제 줄바꿈 기준 20줄을 초과하면 기본적으로 접힌 상태로 표시됩니다.
- "... 더보기" 버튼을 누르면 전체 내용을 펼칩니다.
- "접기"로 다시 축소할 수 있습니다.
- 접힌 긴 메모를 직접 편집하려고 클릭하면 자동으로 펼쳐진 뒤 편집됩니다.

============================================================
16. Sync 동작 개선
============================================================

- Calendar 입력 / Drag / 설정 변경 시 매번 Supabase Sync를 실행하던 방식을 제거했습니다.
- Calendar 변경은 우선 localStorage / RTCore 메모리에 즉시 저장됩니다.
- 서버 자동 Sync는 기존 정책대로 약 5분 단위로 수행합니다.
- 수동 Sync 버튼은 즉시 Sync합니다.

- Sync 중 Calendar 입력창에 포커스가 있으면 화면 재렌더링을 미뤄
  타이핑 중 커서가 끊기는 문제를 줄였습니다.

============================================================
17. Calendar UI / 가독성
============================================================

- Daily / Weekly TimeTable의 폰트 크기를 확대했습니다.
- Weekly의 각 날짜 열 최소 폭을 넓혀 억지로 텍스트를 압축하지 않도록 했습니다.
- 필요 시 Weekly는 가로 스크롤을 사용합니다.
- TimeBlock 액션 버튼은 제목 영역을 많이 차지하지 않도록 Hover 중심 Overlay 형태로 정리했습니다.
- 30분 단위 선은 유지하면서 시간 숫자는 정시에만 표시합니다.
- Floating + 버튼은 화면 우측 하단에 고정됩니다.
